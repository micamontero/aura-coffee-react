# AURA Coffee Roasters ☕

E-commerce de café de especialidad desarrollado como proyecto integrador para la materia de Desarrollo Full Stack.

## Descripción

AURA Coffee Roasters es una tienda online de cafés de especialidad, accesorios y kits para amantes del café. El proyecto fue construido en dos etapas: primero como sitio estático en HTML y CSS, y luego migrado a React con conexión a una API real mediante MockAPI.

## Tecnologías utilizadas

- React 19 + Vite
- React Router v8
- React Hook Form
- Axios
- MockAPI (base de datos simulada)
- SweetAlert2
- CSS propio con variables y diseño responsive

## Páginas

- **Home** — Banner, hero, productos destacados desde MockAPI y sección de beneficios
- **Shop** — Catálogo completo con filtros por categoría
- **Product Detail** — Detalle de producto individual con datos desde MockAPI
- **Register** — Formulario de registro con validaciones y POST a MockAPI
- **Login** — Formulario de inicio de sesión
- **Admin Productos** — Tabla de productos con alta, edición y baja (CRUD completo)
- **Admin Usuarios** — Tabla de usuarios con alta, edición y baja (CRUD completo)
- **Nosotros** — Historia del proyecto y presentación del desarrollador
- **Contacto** — Formulario de contacto y mapa de ubicación

## Instalación

```bash
git clone https://github.com/micamontero/aura-coffee-roasters.git
cd aura-coffee-roasters
npm install
npm run dev
```
